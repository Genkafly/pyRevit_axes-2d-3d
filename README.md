# Оси 2D/3D — расширение для pyRevit

Кнопка для Autodesk Revit, которая переключает оси (`Grid`) и уровни (`Level`)
между режимами **2D** и **3D** в активном виде.

- **2D** — у оси или уровня свои границы в каждом виде.
- **3D** — общие границы элемента для всей модели.

## Что умеет

- берёт выделенные оси и уровни, а если ничего не выделено — все оси и уровни,
  видимые в активном виде;
- переключает **2D ↔ 3D**;
- может принудительно перевести всё в **2D** или в **3D**;
- показывает отчёт: сколько элементов изменилось и какие Revit не дал изменить.

Инструмент работает в планах, потолочных планах, планах зон,
конструктивных планах, разрезах и фасадах.

## Требования

- Autodesk Revit 2018 или новее.
- Установленный pyRevit.

## Установка

### Способ 1. Через pyRevit по ссылке на GitHub

1. Скопируйте ссылку на этот репозиторий.
2. В Revit откройте **pyRevit → Settings → Extensions**.
3. Добавьте расширение по ссылке на репозиторий.
4. Перезапустите Revit.

После запуска кнопка появится на вкладке **pyRevit** в панели **Axes 2D-3D**.

### Способ 2. Вручную

1. Скачайте репозиторий: **Code → Download ZIP**, затем распакуйте.
2. Переименуйте распакованную папку в `Axes2D3D.extension`
   (если она называется иначе).
3. Скопируйте папку сюда:

   `%APPDATA%\pyRevit\Extensions`

4. Полностью закройте и снова откройте Revit.

Внутри папки расширения должны лежать:

```
Axes2D3D.extension\
├── extension.json
├── README.md
└── pyRevit.tab\
    └── Axes 2D-3D.panel\
        └── Axes 2D-3D.pushbutton\
            ├── bundle.yaml
            ├── icon.png
            └── script.py
```

Если скопировать только три файла кнопки, без папок `pyRevit.tab` и
`Axes 2D-3D.panel`, pyRevit расширение не увидит.

## Как пользоваться

1. Откройте план, разрез или фасад.
2. При необходимости выделите нужные оси и уровни.
   Если ничего не выделять, будут обработаны все оси и уровни вида.
3. На вкладке **pyRevit** нажмите **Оси 2D/3D** в панели **Axes 2D-3D**.
4. Выберите режим:
   - **Переключить 2D ↔ 3D** — элементы с общими границами станут 2D,
     остальные — 3D;
   - **Перевести в 2D** — границы будут задаваться отдельно в этом виде;
   - **Перевести в 3D** — вернуть общие границы модели.
5. Посмотрите отчёт: сколько элементов изменилось и что не получилось.

## Ограничения

- Изменения применяются только к **активному виду**, а не ко всем видам сразу.
- Revit не разрешает 2D-границы для элемента, который не может отображаться
  в данном виде. Такие элементы попадут в список ошибок, остальные будут
  обработаны.
- Для уровней режим 2D/3D имеет смысл в разрезах и фасадах.
- В 3D-видах и чертёжных видах инструмент не запускается.

## Если кнопка не появилась

1. Проверьте, что в папке расширения есть `extension.json` и папка `pyRevit.tab`,
   а не только `script.py`, `bundle.yaml` и `icon.png`.
2. Полностью закройте и откройте Revit. Обычного **Reload** может не хватить:
   новые расширения подхватываются при запуске Revit.
3. Откройте **pyRevit → Settings → Extensions** и убедитесь, что расширение
   **Axes 2D-3D** есть в списке и включено.
4. Проверьте, что установлен pyRevit и он загружается в вашей версии Revit.

## Удаление

Удалите папку `Axes2D3D.extension` из:

`%APPDATA%\pyRevit\Extensions`

Затем перезапустите Revit.

## Для публикации на GitHub

В репозитории должны лежать **содержимое** этой папки, а не сама папка
`Axes2D3D.extension`:

- `extension.json`
- `pyRevit.tab`
- `README.md`

После создания репозитория откройте `extension.json` на GitHub, нажмите
карандаш и укажите ссылку на репозиторий в поле `"url"`:

```json
"url": "https://github.com/ВАШ_ЛОГИН/axes-2d-3d"
```

Затем сохраните изменение кнопкой **Commit changes**.
